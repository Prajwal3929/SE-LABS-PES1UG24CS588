# Static Code Analysis - Issues Log

## Identified Issues and Resolutions

| Issue | Type | Line(s) | Description | Fix Approach |
|---|---|---|---|---|
| Command Injection via Shell (`B602`) | Security (High) | 61 | `subprocess.call("cp services.json " + folder, shell=True)` executes shell commands using unvalidated string concatenation. If `folder` contains shell metacharacters (e.g., `; rm -rf /`), arbitrary commands can be executed (CWE-78). | Replace `subprocess.call` with Python's standard library `shutil.copy("services.json", folder)`, eliminating the shell process and preventing shell injection entirely. Remove `import subprocess`. |
| Weak Cryptographic Hash MD5 (`B324`) | Security (High) | 39 | `hashlib.md5(vehicleNo.encode()).hexdigest()[:8]` uses the legacy MD5 hashing algorithm, which is cryptographically broken and vulnerable to collision attacks (CWE-327). | Specify `usedforsecurity=False` in `hashlib.md5(vehicle_no.encode(), usedforsecurity=False).hexdigest()[:8]` to explicitly document and enforce that the hash is purely for unique ID generation, resolving Bandit's high-severity warning while preserving identical demo output. |
| Hardcoded Sensitive Password (`B105`) | Security (Medium) | 8 | `ADMIN_PASSWORD = "garage-demo"` hardcodes administrative credentials directly into source code, exposing sensitive secrets in version control (CWE-259). | Fetch the secret from the environment with `os.getenv("ADMIN_PASSWORD", "garage-demo")`, adhering to 12-factor application security best practices. |
| Mutable Default Argument (`W0102`) | Bug / Quality (High) | 12 | `history=[]` defines a mutable default argument. In Python, default arguments are evaluated only once at function definition time, causing `history` state to be inadvertently shared across subsequent function calls. | Set default argument to `history=None` and initialize `if history is None: history = []` inside the function body so each invocation receives a fresh list unless explicitly provided. |
| Broad Exception Clause (`W0718`) | Bug / Quality (Medium) | 23 | `except Exception:` catches all exceptions indiscriminately, potentially masking unrelated issues such as `KeyboardInterrupt`, memory errors, or type errors. | Catch the specific `KeyError` exception that occurs when looking up a non-existent vehicle key in `service_records`. |
| Unspecified File Encoding (`W1514`) | Quality / Portability | 50 | `open(fileName, "w")` opens a file without explicitly specifying character encoding, making file I/O behavior dependent on the operating system's default locale. | Explicitly pass `encoding="utf-8"` to the `open()` context manager: `open(file_name, "w", encoding="utf-8")`. |
| Non-conforming Naming Conventions (`C0103`) | Style / Convention | 12, 20, 31, 38, 42, 49, 54, 59, 64 | Functions (`addService`, `cancelService`, `getTotalCost`, `jobCardId`, `busiestVehicle`, `saveRecords`, `loadRecords`, `backupRecords`) and arguments/variables (`vehicleNo`, `serviceType`, `totalCost`, `fileName`) violate PEP 8 snake_case style. | Refactor all function names, parameter names, and local variable names to standard Python `snake_case` (e.g., `add_service`, `vehicle_no`, `total_cost`). |
| Missing Module and Function Docstrings (`C0114`, `C0116`) | Quality / Maintainability | 1, 12, 20, 31, 38, 42, 49, 54, 59, 64 | The module and its constituent functions lack docstrings, violating PEP 257 standards and reducing codebase maintainability and self-documentation. | Add structured docstrings explaining the purpose, arguments, and behavior of the module and every function. |
| Formatting and Spacing Violations (`E231`, `E225`, `E302`, `E501`) | Style (PEP 8) | 7, 43, 49, 77 | Code violates PEP 8 rules: missing whitespace after comma (`"General": 2500,"Brake Check": 1200`), missing whitespace around operator (`best=None`), insufficient blank lines (found 1 instead of 2 before top-level functions), and line length exceeding 79 characters. | Correct whitespace around commas and operators, ensure exactly 2 blank lines between top-level functions, and wrap long statements across lines to comply with the 79-character PEP 8 limit. |
